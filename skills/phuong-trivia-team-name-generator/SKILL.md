# Trivia Team Name Generator

## What It Does

Turns a theme, an inside joke, or a topic someone cares about into a short list of pun-based trivia team names. It leans on wordplay patterns (rhymes, portmanteaus, "Fellowship of the ___" style templates) so the names sound clever rather than generic.

## When To Use It

Use this skill the night before trivia when a team can't agree on a name, or when someone wants a themed name tied to the bar's trivia category, a work outing, or a running joke in the friend group.

## Inputs

- A theme or topic (e.g., "80s movies," "marine biology," "tacos").
- Optional inside joke or phrase the group wants worked in.
- Desired tone: silly, punny, mildly competitive-sounding, or mock-serious.
- How many name options to generate.

## Output

- A list of 5-10 candidate team names, grouped loosely by style (pun, pop-culture reference, mock-serious).
- A one-line explanation of the wordplay for any name that isn't obvious.
- A single "safe pick" if the group wants one name without deliberating.

## Example Prompt

```text
Our trivia team loves 90s sitcoms and one of us just adopted a cat named
Waffles. Give me 8 pun team name options, mostly silly, and throw in a
mock-serious one too.
```

## Safety Notes

This is a fictional practice skill for a GitHub training exercise. Use invented themes and made-up group details only. Do not include real personal names, private jokes tied to identifiable people, company names, customer data, or anything copied from a real workplace document.
