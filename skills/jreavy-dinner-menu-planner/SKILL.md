# Dinner Menu Planner

## What It Does

Helps create a fictional weekly dinner menu with themed nights (taco Tuesday, pasta night, etc.). Suggests meal ideas based on theme, checks for ingredient variety throughout the week, and generates a simple shopping list stub.

## When To Use It

Use this skill when a learner wants to organize a fictional restaurant, meal-prep service, or home dinner planning scenario without using real customer data or personal recipes.

## Inputs

- A fictional restaurant or household name.
- Number of days to plan for (e.g., 7 days).
- Preferred cuisine themes (e.g., Italian, Mexican, vegetarian).
- Any dietary restrictions or preferences for the fictional scenario.

## Output

- A day-by-day menu with theme and meal suggestions.
- A note about ingredient variety and cross-day pairing ideas.
- A simple, rough shopping list organized by ingredient type.

## Example Prompt

```text
I'm planning a fictional 7-day menu for a fake community meal-share program. I want theme nights like Taco Tuesday, Pasta Thursday, and a weekend brunch special. Help me create a balanced menu and suggest what ingredients I might need.
```

## Safety Notes

Use entirely fictional scenarios and invented recipes only. Do not use real restaurant menus, actual customer dietary needs, personal meal preferences, or any real business operations.
