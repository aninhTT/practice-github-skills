# Garden Bed Rotation Planner

## What It Does

Builds a season-by-season crop rotation plan for a set of imaginary raised garden beds. It groups crops into plant families (for example legumes, brassicas, roots, and leafy greens), then moves each family to a different bed each season so the same family does not sit in the same bed two seasons in a row. It also flags simple companion pairings and notes when a bed could use a cover crop or a rest.

## When To Use It

Use this skill when you want to practice describing a light planning workflow with a made-up garden layout, and you do not want to rely on any real personal, household, or business data.

## Inputs

- The number of imaginary raised beds and a made-up label for each (for example "Bed A", "Bed B").
- A fictional list of crops you want to grow.
- The number of seasons to plan for (for example three or four).
- Optional: any invented constraints, such as a bed that is always shady or one you want to leave to rest.

## Output

- A rotation table showing which crop family lands in each bed for each season.
- A short list of companion-planting suggestions.
- A few notes on when to add a cover crop or rest a bed.

## Example Prompt

```text
I have four made-up raised beds (A, B, C, D) and want to grow tomatoes, bush beans, kale, carrots, and garlic. Plan a four-season rotation so no plant family repeats in the same bed, and suggest a couple of companion pairings.
```

## Safety Notes

- This is a fictional skill for GitHub practice. Use invented garden layouts and crop lists only.
- Do not include real addresses, property details, personal records, customer data, or any company or private information.
- All planting advice here is illustrative and made up for the exercise, not real horticultural guidance.
