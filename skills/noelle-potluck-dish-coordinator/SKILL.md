# Noelle Potluck Dish Coordinator

## What It Does

Takes a fictional guest list and turns it into a balanced potluck plan. It assigns each guest a course (appetizer, main, side, dessert, or drinks), makes sure no course is over- or under-covered, and produces a simple sign-up table so the invented gathering has a well-rounded menu.

## When To Use It

Use this skill when a learner wants to practice describing a lightweight event-planning workflow with a made-up guest list, without using any real names or private event details.

## Inputs

- A fictional list of guest names.
- The number of expected attendees.
- Any dietary preferences to invent (for example: vegetarian, gluten-free).
- Optional course counts the learner wants to target.

## Output

A dish assignment table mapping each fictional guest to a course, a summary of how many dishes fall under each course, and a short checklist of gaps to fill before the invented potluck.

## Example Prompt

```text
I'm planning a fake potluck for 8 made-up guests. Two are vegetarian. Assign everyone a course so we have enough appetizers, mains, sides, and desserts, and show me the sign-up table.
```

## Safety Notes

Use invented guests, dishes, and preferences only. Do not use real people's names, contact details, actual event invitations, or any private or personal information.
