# Jennifer Potluck Dish Planner

## What It Does

Helps plan a fictional potluck by turning a guest list and a few preferences into a balanced dish assignment. It suggests who brings what across categories (appetizers, mains, sides, desserts, drinks) so there are no gaps and not five bowls of the same pasta salad.

## When To Use It

Use this skill when a learner wants to practice describing a simple event-coordination workflow with made-up guests and dishes, without using any real names or private event details.

## Inputs

- A fictional guest list (invented names only).
- The number of dish categories to cover.
- Any made-up dietary notes (for example, "one vegetarian, one gluten-free").
- An optional headcount so portions can be suggested.

## Output

A tidy dish assignment table that maps each fictional guest to a category and a suggested dish, plus a short checklist of any categories still unfilled.

## Example Prompt

```text
I'm planning a pretend potluck for 8 invented guests. Cover appetizers, mains, sides, and desserts, and note that two guests are vegetarian. Suggest who brings what.
```

## Safety Notes

Use invented guest names and fictional dishes only. Do not include real people, real contact details, real event addresses, company events, or any private or personal information.
