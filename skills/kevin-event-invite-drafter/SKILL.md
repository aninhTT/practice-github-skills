# Kevin Event Invite Drafter

## What It Does

Drafts a fictional event invitation email for a made-up gathering, using a specified tone and event details.

## When To Use It

Use this skill when practicing how to structure an invitation workflow without using real event details or attendee information.

## Inputs

- A fictional event name and date.
- The desired tone (formal, casual, festive, etc.).
- A made-up venue or location.
- Any key details to highlight (dress code, RSVP deadline, activities).

## Output

A polished fictional invitation email and a short note explaining the tone and structural choices.

## Example Prompt

```text
Draft a casual invitation for a fictional neighborhood board game night happening on a Saturday evening at a community center called the Maplewood Hub. Include an RSVP deadline and a note about bringing a snack to share.
```

## Safety Notes

Do not include real event details, real attendee names, company calendars, private venues, or any personal or organizational information.
