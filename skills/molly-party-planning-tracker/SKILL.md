# Molly Party Planning Tracker

## What It Does

Keeps a simple checklist for a fictional party. It sorts the to-dos into groups like venue, food, decorations, invites, and music, gives each one a due date counting back from the party date, and flags anything that is overdue or coming up this week.

## When To Use It

Use this skill when someone is hosting a made-up get-together and wants all the details in one place instead of spread across sticky notes and group texts. It works best a few weeks before the party, when there is still time to book things, and again in the last few days to see what is left.

## Inputs

- The party date and a rough guest count.
- The party theme or style, such as "backyard taco night" or "80s roller disco."
- A list of tasks, with any that are already done marked.
- Optional budget for each category.
- Optional helpers and the tasks they have offered to take on.

## Output

A tracker table with each task's category, owner, due date, and status (not started, in progress, done). Below it, a short "this week" list and a one-line readiness check such as "on track" or "three items overdue."

## Example Prompt

```text
I'm planning a fictional 80s roller disco birthday party for 25 guests on
March 14. Done so far: booked the rink, sent invites. Still to do: order the
cake, make a playlist, buy glow sticks, and pick up the rental skates. My
friend Pat offered to handle the playlist. Can you build my planning tracker?
```

## Safety Notes

Use only the invented party details given in the prompt. Do not pull from personal files, personal history, private notes, calendars, company information, customer data, credentials, or real workplace documents. Names and vendors in examples should be made up. This is a practice exercise, not a real event-planning tool.
