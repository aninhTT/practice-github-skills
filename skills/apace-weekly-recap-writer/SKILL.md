# Weekly Recap Writer

## What It Does

Turns a raw bullet list of weekly notes into a polished, concise weekly recap suitable for sharing with a team or manager.

## When To Use It

Use this skill at the end of a work week when you have scattered notes, completed tasks, or random updates and want to turn them into a clean summary paragraph or short structured recap.

## Inputs

- A bullet list of raw weekly notes (tasks done, blockers, highlights)
- Optional: recipient context (e.g., "for my manager", "for a team standup")
- Optional: desired tone (e.g., casual, formal)

## Output

A short weekly recap (2–4 paragraphs or a structured summary) covering:
- Key accomplishments
- Blockers or open items
- Planned focus for next week

## Example Prompt

```
Here are my notes from this week:
- Finished the onboarding doc draft
- Had a sync with the design team about the new dashboard
- Still waiting on feedback from Jordan on the proposal
- Started reading up on accessibility guidelines

Write a weekly recap I can share with my manager. Keep it concise and professional.
```

## Safety Notes

- Do not include personal, confidential, or company-sensitive information in the notes you provide.
- Use fictional names and project titles when testing this skill.
- This skill produces a summary only — always review before sending.
