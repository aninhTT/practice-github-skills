# Rob Fantasy Team Name Generator

## What It Does

Invents playful, fictional team names for a casual fantasy sports league. Given a
sport and a couple of favorite things (an animal, a food, a hobby), it returns a short
list of punny, family-friendly name ideas along with an optional one-line tagline for
each. Everything is made up for fun and practice.

## When To Use It

Use it when you're joining or running a casual fantasy league and want a quick, silly
team name without brainstorming from scratch. Handy right before a draft, when renaming
a team mid-season, or when a group needs a batch of names for several players at once.

## Inputs

- Sport (for example: football, basketball, baseball, soccer)
- One or two favorite things (an animal, a food, a hobby, a place)
- Optional: tone preference (goofy, competitive, or wholesome)
- Optional: how many name ideas to return (default 5)

## Output

A short list of team name ideas, each containing:

- A punny team name
- An optional one-line tagline
- A note on which input inspired it

Example output shape:

> 1. **The Waffle Blitz** - "Syrup now, sacks later." (from: football + waffles)
> 2. **Slam Dunk Otters** - "Small paws, big buckets." (from: basketball + otters)

## Example Prompt

> Give me 5 goofy fantasy football team names. I like otters and tacos.

## Safety Notes

- Everything produced is fictional and for practice only. Names, taglines, and any
  players or leagues referenced are invented.
- Do not use real people's names, real team trademarks, or any private, company,
  customer, or sensitive information.
- Keep all suggestions family-friendly and public-safe.
