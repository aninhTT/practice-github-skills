# Alex Board Game Night Planner

## What It Does

Turns a guest count and a shelf of games into a suggested play order for a board game night. It groups games by how long they take and how many people they fit, then proposes a running order with rough timings and a light snack break in the middle.

## When To Use It

Use this skill when a learner wants to practice describing a simple planning workflow using a fun, fictional example. It is meant for a casual game night with friends, not for any real event, venue, or attendee data.

## Inputs

- The number of guests expected.
- A fictional list of games with their player ranges and rough play times.
- The total time available for the night.
- Any preference, like "start light and get more strategic" or "save the longest game for last."

## Output

A suggested running order that lists each game, when to start it, how long to budget, and where to slot a snack break. It also flags any game that will not fit the guest count so it can be swapped out.

## Example Prompt

```text
Six friends are coming over for about four hours. My fictional shelf has a 20-minute party game for up to 8, a 45-minute card game for 3-5, and a 90-minute strategy game for 2-4. Help me plan a play order that starts light and ends with the strategy game.
```

## Safety Notes

Use invented game nights and made-up game lists only. Do not include real guest names, contact details, addresses, calendar data, or anything from a real event. Keep everything fictional and safe for a public repository.
