# Jlangan Trailhead Difficulty Rater

## What It Does

Takes a fictional hiking trail description and produces a simple difficulty rating (Easy, Moderate, Hard, or Expert) along with a short explanation and a suggested gear list. It weighs made-up factors like distance, elevation gain, terrain type, and expected weather to help a pretend hiker decide if a trail is a good fit.

## When To Use It

Use this skill when a learner wants to practice turning a loose, invented trail description into a structured, easy-to-scan rating card. It is meant for imaginary trails only, as a way to practice the GitHub contribution flow.

## Inputs

- A fictional trail name.
- Round-trip distance (in miles or kilometers).
- Total elevation gain.
- Terrain notes (for example: smooth path, loose rock, river crossing).
- Expected conditions (for example: sunny, muddy, snow near the summit).
- The pretend hiker's experience level.

## Output

A short rating card containing:

- A difficulty label (Easy, Moderate, Hard, or Expert).
- One or two sentences explaining why that label was chosen.
- A suggested gear checklist tailored to the difficulty and conditions.
- One safety reminder appropriate for the fictional trail.

## Example Prompt

```text
Rate this fake trail for me: "Cedar Hollow Loop," 7 miles round trip, 2,300 ft of elevation gain, loose gravel switchbacks with one shallow creek crossing, expected to be sunny but muddy after rain. The hiker is a confident beginner. Give me a difficulty rating, why, and a gear list.
```

## Safety Notes

Use invented trails and fictional conditions only. Do not use real GPS coordinates, real trail data, personal location history, or any private information. This skill is a practice exercise and its ratings should never be relied on for real-world hiking, navigation, or safety decisions.
