# Whitney Plant Care Reminder Writer

## What It Does

Turns a fictional list of houseplants into a friendly care schedule, drafting watering, light, and feeding reminders for each plant so a learner can practice describing a simple recurring-reminder workflow.

## When To Use It

Use this skill when a learner wants to practice writing a plant-care reminder routine from a made-up plant list, without relying on any real personal, home, or private information.

## Inputs

- A fictional list of plant names (invented or common species).
- Rough light conditions for each plant (for example: bright, medium, low).
- How often each plant should be watered, if known.
- Any fake notes the learner wants to add, such as "gift plant" or "office desk".

## Output

A tidy per-plant reminder schedule that includes a watering cadence, a light tip, an optional feeding note, and a short weekly checklist the learner can copy into any reminders tool.

## Example Prompt

```text
Here is a fake list of houseplants: a pothos in medium light, a snake plant in low light, and a basil pot in bright light. Draft a simple weekly care reminder schedule for each one.
```

## Safety Notes

Use invented plant lists and fictional details only. Do not include real home addresses, personal routines, private schedules, customer data, company information, or anything sensitive. This skill is for GitHub practice, so keep every example public-safe.
