# Andrew Fantasy Team Name Generator

## What It Does

Invents a short list of punny, fictional fantasy-league team names from a few playful inputs. It takes a made-up sport, a favorite (fictional) player nickname, and a vibe, then returns several name options with a one-line explanation of the joke behind each one so you can pick a favorite.

## When To Use It

Use this skill when a learner wants to practice describing a lighthearted, creative workflow using a completely fictional example. It is meant for a pretend fantasy league among friends, not for any real league, roster, or player data.

## Inputs

- A made-up sport or league type, like "fantasy space-racing" or "backyard croquet league."
- A fictional player nickname or mascot to build a pun around, like "The Comet" or "Sir Waddles."
- A desired vibe, such as "silly," "intimidating," or "old-timey."
- How many name options you want back (for example, five).

## Output

A numbered list of team name suggestions. Each entry includes the team name and a short note explaining the wordplay or theme, plus a final line suggesting which option best matches the requested vibe.

## Example Prompt

```text
Make five silly team names for a fictional fantasy space-racing league. Build the puns around a made-up star pilot nicknamed "The Comet." Keep it goofy, and tell me the joke behind each name.
```

## Safety Notes

Use only invented sports, made-up nicknames, and imaginary leagues. Do not include real people, real teammates, real league names, contact details, or anything from an actual fantasy league or workplace pool. Keep everything fictional and safe for a public repository.
